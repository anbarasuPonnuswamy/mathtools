# Calcify — Deploy Guide

## Files
- `index.html` — Landing page / tool directory
- `mortgage-calculator/index.html` — Full mortgage calculator (PITI, PMI, amortization)
- `calculators/index.html` — All other calculators (BMI, EMI, Tax, Age, Recipe, etc.)
- `sitemap.xml` — SEO sitemap (update domain before deploying)
- `robots.txt` — Search engine crawl rules (update domain before deploying)
- `_redirects` — Cloudflare Pages clean URL routing
- `_headers` — Security + cache headers for Cloudflare Pages

## Deploy to Cloudflare Pages

1. Go to https://pages.cloudflare.com
2. Click "Create a project" → "Direct Upload"
3. Drag this entire folder into the upload area
4. Set your custom domain in Settings → Custom Domains
5. Update `sitemap.xml` and `robots.txt` with your real domain

## Clean URLs
These URLs will work out of the box on Cloudflare Pages:
- yourdomain.com/
- yourdomain.com/mortgage-calculator
- yourdomain.com/calculators

## Before You Go Live
- [ ] Replace "Calcify" with your brand name across all files
- [ ] Update domain in sitemap.xml and robots.txt
- [ ] Apply for Google AdSense (after 30 days of traffic)
- [ ] Add Google Analytics or Cloudflare Web Analytics snippet
- [ ] Submit sitemap.xml to Google Search Console
